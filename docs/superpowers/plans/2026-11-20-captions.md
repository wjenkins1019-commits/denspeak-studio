# Caption Export Implementation Plan (inline execution, no git)

**Goal:** SRT/VTT downloads beside audio export buttons, timed by transcription.

**Architecture:** Whisper worker gains a timestamps mode; `transcribeTimed`
returns words; pure `captions.ts` builds cues + formats; Player owns the
transcribe → download flow with progress/error states.

## Global Constraints

- Work only in `chatter-box-app/`; no new dependencies; no git.
- No render-path changes.

## Review Focus

- Model that won't return word timestamps must degrade to chunk cues, never crash — pinned by normalizer test.
- Empty/garbage audio must show an error, not an empty download — pinned by code (no words → error).
- Long files: transcription runs in the worker; UI stays responsive — by construction, browser-checked.
