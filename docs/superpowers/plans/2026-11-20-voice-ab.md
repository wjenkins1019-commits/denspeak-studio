# Voice A/B Compare Implementation Plan

> **For agentic workers:** inline execution by the session model; no git here so
> no commits/worktrees — the ledger is the final message's Rulings list.

**Goal:** A compare section in Studio that renders one sample with two voices
and plays them through two synced players.

**Architecture:** Pure helpers in `src/lib/compare.ts` (group id, sample
default, job-side matching — unit-tested in node); `VoiceCompare.tsx`
owns pickers/sample/players and enqueues two `compare`-group jobs reusing the
global queue; Studio renders it below the narration card with its live
voice/script/settings.

**Tech Stack:** TypeScript, React, existing renderQueue/voices/settings modules.

**Spec:** `docs/superpowers/specs/2026-11-20-voice-ab-design.md`

## Global Constraints

- Work only in `chatter-box-app/`; no new dependencies.
- Engine never driven twice at once — the queue already serializes; do not add concurrency.
- Bank voices only in the pickers (no saved/clone ids).
- No git: no commit steps; verify with typecheck + tests + browser instead.

## Review Focus

- Empty sample must disable Render both, never enqueue — pinned in Task 2 browser check.
- A side whose voice model is still downloading must show progress, not silence — pinned in Task 2.
- Switching Studio voice mid-compare must not retarget queued jobs — pinned by code (voice snapshotted in job input).
- Object URLs revoked on unmount/new render (AbCompare pattern) — pinned by code, checked in review.

### Task 2: VoiceCompare component + Studio wiring

**Files:** Create `src/components/VoiceCompare.tsx`; modify `src/views/Studio.tsx`.

**Consumes:** Task 1 helpers; `enqueueJobs/clearGroup/cancelGroup/useRenderQueue/getJobs`
from renderQueue; `VOICES/languageName/voiceLabel` from voices; `NarrationSettings` type.

**Props:** `{ voiceA: string; script: string; settings: NarrationSettings }` —
B defaults to `DEFAULT_VOICE` (Leah) unless A already is Leah (then B = Ryan
`en_US-ryan-high`); sample state init from `defaultSample(script)` once.

**Behavior:** grouped voice `<select>`s (optgroups by language, bank voices);
Render both disabled when sample empty or busy; jobs `{ group: COMPARE_GROUP,
chapterIndex: 0|1, settings: { ...settings, voice: { baseVoiceId, isClone: false,
cloneName: '' } }, voiceId }`; per-side status line (queued/working %/failed +
error); done sides render `<audio controls>` from `take.blob`; `onPlay` one
side pauses the other; seek-lock toggle (default on) mirrors `currentTime` on
`seeked`; single Cancel button (`cancelGroup`); download link per finished side.

- [ ] Step 1: Create component + wire `<VoiceCompare voiceA={voiceId} script={script} settings={narrationSettings()} />` into Studio below the narration card.
- [ ] Step 2: `npm run typecheck` clean; `npm test` green.
- [ ] Step 3: Browser check (dev server): pick two voices incl. one needing a model download, short sample, Render both, confirm sequential jobs + both players appear; play A pauses B and vice versa; seek with lock on moves both; cancel works; empty sample disables the button.
